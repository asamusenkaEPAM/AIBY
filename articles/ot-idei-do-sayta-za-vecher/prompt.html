Create a modern, elegant, fully responsive landing page for an English Conversation Club based on the following design specifications.

1. Overall Design

Build a welcoming, premium-looking community website inspired by warm Mediterranean aesthetics and modern editorial web design.

Visual direction:

- Warm minimalism with soft pastel backgrounds.
- Elegant editorial typography.
- Clean, spacious layout with generous whitespace.
- Subtle rounded corners and delicate shadows.
- Friendly, sophisticated, inviting atmosphere.
- Minimal decorative hand-drawn elements.
- A professional design that feels human rather than corporate.

Color palette:

- Main background: warm ivory "#FAF3EC"
- Secondary background: soft peach "#F5E8DC"
- Primary text: deep navy "#243849"
- Accent color: muted terracotta/golden orange "#E8AA68"
- Buttons: muted dark blue "#385775"
- Cards: warm off-white "#FFF9F4"

Typography:

- Headings: Playfair Display or another elegant serif font.
- Body text: DM Sans or Inter.
- Large expressive headings with comfortable line spacing.

2. Header / Navigation

Create a clean horizontal navigation bar.

Left side:

- Minimal outlined speech bubble logo.
- Brand name displayed on two lines: "English Conversation Club".

Center:

- Home
- About
- Events
- Topics
- Contact

Right side:

- Rounded dark blue button: "Join Us".

The header should have generous padding and a subtle warm background.

3. Hero Section

Create a split-screen hero layout.

Left column (45%):

Large elegant serif headline, broken into three lines:

"Real People
Real Conversations
A Brighter You"

Below the headline, add supporting text:

"Practice English. Meet new people. Explore the world together."

Add a rounded primary CTA button:

"Join the Club"

Use dark navy text, warm backgrounds, and generous spacing.

Include small decorative orange hand-drawn sun rays or abstract curved strokes near the headline.

Right column (55%):

Display a large, beautiful Mediterranean travel photograph featuring Perast, Montenegro, or the Bay of Kotor.

The image should feature:

- Adriatic coastal scenery.
- Historic stone buildings with terracotta rooftops.
- Mountains rising behind the sea.
- Warm late-afternoon sunlight.
- Natural, vibrant but tasteful colors.

Use softly rounded asymmetric corners for the image.

The image should dominate the right side while maintaining balance with the text.

4. Feature Cards

Directly below the hero section, create a horizontal row of four evenly spaced cards.

Each card should feature a thin navy outline icon, a short label, and subtle hover interaction.

Cards:

1. Friendly Community — outlined group-of-people icon.
2. Interesting Topics — outlined conversation bubbles icon.
3. Online & Offline — outlined calendar icon.
4. All Levels Welcome — outlined growth/bar-chart icon.

Styling:

- Warm off-white backgrounds.
- Rounded corners (12–16px).
- Generous padding.
- Very subtle shadows.
- Consistent icon sizes.
- Centered content.

5. Additional Sections

Extend the landing page while preserving the same visual identity.

Include:

- About the Club — welcoming introduction.
- Upcoming Events — elegant cards for conversation meetings.
- Conversation Topics — examples of interesting subjects.
- How It Works — three simple steps to join.
- Join Our Community — prominent call-to-action section.
- Footer — contact information, social links, and navigation.

Keep the content natural and welcoming.

Avoid making the website look like a corporate language school. It should feel like a genuine social community where people meet, make friends, and practice English.

6. Responsive Design

The website must work beautifully on desktop, tablet, and mobile.

On mobile:

- Stack hero text above the photograph.
- Use a collapsible navigation menu.
- Display feature cards in a two-column grid or vertical stack.
- Maintain generous spacing and legible typography.
- Ensure all buttons are touch-friendly.

7. Implementation

Build a fully functional website using React and Tailwind CSS.

Requirements:

- Clean, maintainable component structure.
- Semantic HTML and accessible navigation.
- Smooth scrolling between sections.
- Subtle hover effects and micro-interactions.
- Functional responsive mobile menu.
- Optimized images.
- Lucide icons.
- Google Fonts.
- Good accessibility and performance.

All navigation links and buttons must have meaningful behavior.

8. Important Visual Instructions

The result should closely resemble the provided reference design in composition, typography, palette, spacing, and overall atmosphere.

Create the actual website UI, not a laptop mockup, screenshot, or image of a website.

Prioritize visual quality, a cohesive design system, and a polished production-ready appearance.
