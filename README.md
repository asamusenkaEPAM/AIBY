# Дополнение к статье «Поиск проекта в эпоху AI»

Локальный статический сайт состоит из трёх частей:

- `index.html` — входная страница;
- `test.html` — тест из 10 вопросов с персональным результатом;
- `sources.html` — фильтруемый каталог проверенных источников.

## Локальный просмотр

Для корректной навигации между страницами запускайте папку через локальный HTTP-сервер, а не открывайте файлы через `file://`.

## Редактирование

Вопросы и источники находятся в `content.js`. Логика теста — в `test.js`, общий дизайн — в `style.css`.
