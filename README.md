# AI BY — интерактивные дополнения к статьям

Этот репозиторий содержит исходный код сайта AI BY с интерактивными дополнениями к опубликованным статьям. Здесь читатели могут проверить себя, изучить источники и глубже разобраться в теме, не перегружая основной текст статьи.

**[Открыть сайт](https://asamusenkaepam.github.io/AIBY/)**

Для каждой статьи есть отдельный раздел:

- коротким интерактивным тестом;
- источниками, подтверждающими факты и цифры из статьи;
- дополнительными материалами по теме.

## Как устроен репозиторий

Сайт написан на обычных HTML, CSS и JavaScript и публикуется через GitHub Pages. Стили и логика тестов общие, а вопросы, ответы и ссылки каждой статьи находятся в её папке:

```text
articles/
  poisk-proekta-v-epohu-ai/
    index.html    — обзор дополнения
    test.html     — страница теста
    sources.html  — каталог источников
    content.js    — вопросы, ответы и ссылки
examples/
  index.html      — витрина всех примеров
  assets/         — общие стили и сценарии
  */index.html    — самостоятельные сайты
```

Чтобы добавить новую статью, достаточно создать для неё папку в `articles/` и добавить карточку на главную страницу.

## Локальный просмотр

Для корректной навигации между страницами проект нужно запускать через локальный HTTP-сервер. Открытие файлов напрямую через `file://` не поддерживается.
