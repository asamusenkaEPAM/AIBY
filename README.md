# AI BY GitHub Pages

Готовый статический сайт с подборкой ссылок и тестом по основам AI.

## Как изменить содержимое

Откройте `content.js`:

- массив `resources` содержит карточки со ссылками;
- массив `quizQuestions` содержит вопросы, варианты ответов и объяснения;
- `correct` — индекс правильного варианта, начиная с нуля.

## Как опубликовать

1. Создайте публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы из этой папки.
3. Откройте **Settings → Pages**.
4. В разделе **Build and deployment** выберите **Deploy from a branch**.
5. Выберите ветку **main**, папку **/(root)** и нажмите **Save**.
6. Через несколько минут сайт появится по адресу `https://USERNAME.github.io/REPOSITORY/`.

Для адреса `https://USERNAME.github.io/` назовите репозиторий `USERNAME.github.io`.

## Локальный просмотр

Можно просто открыть `index.html` в браузере. Для более точной проверки запустите в папке проекта любой локальный HTTP-сервер.
