# Дополнения к статьям

Главная страница — каталог интерактивных дополнений. Материалы каждой статьи находятся в отдельной папке:

```text
articles/
  poisk-proekta-v-epohu-ai/
    index.html    — обзор дополнения
    test.html     — тест
    sources.html  — каталог источников
    content.js    — вопросы и ссылки этой статьи
```

`style.css` и `test.js` общие для всех статей. Старые адреса `/test.html` и `/sources.html` перенаправляют на первый материал.

## Как добавить следующую статью

1. Создать новую папку внутри `articles/`.
2. Скопировать в неё четыре файла из существующего материала и заменить тексты, вопросы и источники.
3. Добавить карточку новой статьи в корневой `index.html`.

## Локальный просмотр

Для корректной навигации запускайте папку через локальный HTTP-сервер, а не открывайте файлы через `file://`.
